The usage of "footer tags" in docs with ai

In this project, I ran a modified version of the main lavadocs branch folder project setup inside OpenCode, where each file was given a footer containing a directive that guides the AI to the next file it should reference. This ensures the AI knows which files to access in the correct order, preventing it from mixing up files or attempting to process a file it isn't ready for yet.

You can find the prompt that i used here: Prompt

In these documents I will try to explain what each AI model did when prompted with the prompt above.

The code that the models generate can be found here — it has the code of all the AIs that are tested right now. It is split into different branches, each branch named after the model that was used to generate the project.

Sessions can also be found on GitHub under the branch "session logs". Each session log is named after the session it came from.

All models are free models:

  • Owl-alpha (OpenRouter)
  • Nemotron 3 ultra free (OpenCode Zen)
  • Big pickle (OpenCode Zen)
  • deepSeek V4 Flash Free (OpenCode Zen)
  • Gemma 4 31B IT (google provider)
